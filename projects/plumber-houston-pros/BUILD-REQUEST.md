# Build Request

Build a large rank-and-rent website named Plumber Houston Pros for the Greater Houston plumbing market.

The deliverable must map the complete plausible plumbing service universe without creating separate pages for wording-only synonyms. It must also map a broad Greater Houston service area, create a materially distinct hyper-local page for every approved market, and use unique content on every service and area page.

Every indexable route must have one unique primary target, canonical URL, H1, meta description, and title. For this build, the title tag must exactly equal the visible H1. Every service page must link to mapped related services and every intended service area. Every area page must link back through the complete plumbing service catalog. Shared directories must remain crawlable and synchronized from one source of truth.

After generation, run exact paragraph duplication, near-duplicate similarity, metadata, schema, linking, navigation, responsive-layout, form, console, sitemap, and build checks. Do not deploy. Do not invent an operator, phone, address, Google Business Profile, license, hours, review, warranty, price, response time, or coverage claim.
