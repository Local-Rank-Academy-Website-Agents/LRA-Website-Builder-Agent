# Drain Cleaning of Houston

Portable static rank-and-rent build with 65 pages, 15 intent-mapped service pages, and 43 hyper-local Greater Houston area pages.

## Commands

```powershell
npm install
npm run dev
npm run check
npm run build
```

Local preview: http://localhost:4181/

Production output: dist/

The source of truth is scripts/site-data.mjs. Generated HTML, KEYWORD-MAP.md, and ROUTE-INVENTORY.csv should be changed through the shared data and generator. The current build is intentionally noindex and form-only. Resolve LAUNCH-BLOCKERS.md before deployment.
